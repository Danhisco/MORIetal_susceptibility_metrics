# Context
Understanding the landscape of susceptibility is fundamental for measles elimination. In this study, we define a novel pipeline to assess measles susceptibility, which leverages age-specific contact patterns as well as the historical build-up of immunity through routine and supplementary immunization activities. We define two novel susceptibility metrics which we analyze alongside estimated susceptible proportions using 2000-2025 data of the State of São Paulo. These metrics are shown to provide complementary views of measles susceptibility, capable of better guiding surveillance and control. 

# Data & Code Availability

__raw_data/__: 
Contains the municipality-level immunization data generated by the cohort-based algorithm (2000–2025).

__source.R__: 
Contains the R code for calculating the three susceptibility metrics (The Susceptible Proportion, The Pocket of Susceptibility, and The Marginal Susceptible Contribution), executing the global and local Moran's I spatial statistics, and running synthesis analyses.

__figuras_e_tabelas_p_submissao.R__: 
Generates all primary and supplementary figures and tables presented in the manuscript.
